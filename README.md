# Demo Day

Orange menu-bar countdown for YC Demo Day. macOS 14 or later.

```bash
curl -fsSL https://raw.githubusercontent.com/matteohorvath/demo-day/main/install.sh | bash
```

That downloads the source, builds `Demo Day.app`, and installs it in `~/Applications`. The Xcode Command Line Tools are required (`xcode-select --install` if `clang` is missing). Run it as yourself, without `sudo`.
